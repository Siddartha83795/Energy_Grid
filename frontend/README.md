# ENERGY ADVISOR — HTML / CSS / JavaScript / ReactJS Frontend

This directory contains the standalone **HTML, CSS, JavaScript, and React.js** frontend for the **ENERGY ADVISOR** B.Tech Computer Science research project.

## Research Workflow Architecture

```
DEVICE
→ ENERGY + SENSOR DATA
→ OPERATING STATE IDENTIFICATION
→ STATE-SPECIFIC EXPECTED ENERGY
→ ACTUAL VS EXPECTED
→ EXCESS ENERGY QUANTIFICATION
→ SENSOR + TEMPORAL ANALYSIS
→ CAUSE ATTRIBUTION
→ RECOMMENDATION
→ BEFORE VS AFTER
→ MEASURED ENERGY SAVING
```

---

## Files Included

- **`index.html`**: The main HTML5 entry point.
- **`css/styles.css`**: Dark futuristic industrial theme with glassmorphism, glowing accents, and typography.
- **`js/data.js`**: Pure JavaScript data store with multi-signal evidence, state baselines, and telemetry feeds.
- **`js/app.jsx`**: Modern React.js component with live telemetry pulse, multi-page router, and interactive graphs.

---

## How to Run

### Method 1: Python Simple Server (Recommended)
From this directory:
```bash
python -m http.server 3000
```
Open: `http://localhost:3000`

### Method 2: Node / Serve / Vite / Live Server
```bash
npx serve .
```

### Method 3: Direct Double Click
Simply double-click `index.html` to open directly in Chrome, Edge, Safari, or Firefox!
